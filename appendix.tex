\section{Numerical Reproducibility}
The file \path{data/results_snapshot_2026-09-22.json} records the aggregate key results and the recall fields needed to check their arithmetic. Participant identifiers in this local file are pseudonymous. It contains neither participant names nor raw response text.

Running \path{verify_snapshot.py} with Python checks complete-pair counts, trial accuracy denominators, condition means, paired differences, paired $t$ statistics, and $d_z$ for the three recall timepoints. The script uses only the Python standard library. It does not re-adjudicate responses, validate exclusions, or independently recalculate the workbook's $p$ values and confidence intervals.

The spreadsheet tabs used for this draft are \emph{V3 Start Here}, \emph{V3 Key Results}, \emph{V3 Data Quality}, \emph{V3 Recall Trials}, \emph{V3 Session Order}, and \emph{V3 Data Dictionary}. The supplied deep link's numeric tab identifier was absent from the current metadata; the named tabs were resolved from the workbook rather than guessed.
